# Sistem Antrian Bank

UAS Mata Kuliah Praktikum Pemrograman Web Dasar — Studi Kasus K7.

## Deskripsi
Sistem Antrian Bank merupakan aplikasi berbasis web yang dirancang untuk membantu pengelolaan antrian nasabah pada layanan Teller dan Customer Service. Sistem menyediakan fitur pengambilan nomor antrian, display nomor yang sedang dipanggil, pengelolaan antrian, serta estimasi waktu tunggu.

## Teknologi
- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap 5

## Fitur
- Pengambilan nomor antrian Teller
- Pengambilan nomor antrian Customer Service
- Nomor antrian otomatis
- Display nomor yang sedang dipanggil
- Pengelolaan antrian
- Status antrian
- Estimasi waktu tunggu
- Filter daftar antrian
